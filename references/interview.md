# 需求澄清

- 使用时机：意图确认前，或已批准的重要承诺发生变化时读取。
- 提问范围：只问缺失或变化的重要选择；可查事实自行检查，技术未知项交给调研。
- 决策归属：结果、验收、成本、数据暴露、兼容性和不可逆影响由用户决定；沉默或“你来选”不算批准。
- 分组提问：同批提出相互独立的选择，每题附推荐项、效果与成本。

# 需求简报

- 结果与受众：为谁解决什么问题，用户最终得到什么。
- 范围与非目标：本次包含什么，明确排除什么。
- 约束与兼容：必须满足的限制及需要保留的兼容性。
- 验收与检查：可观察的通过标准，以及实际可执行的验证方式。
- 交付与深度：研究、设计或产物，以及本次完成到哪一层。
- 默认与待定：推荐默认项和仍需用户决定的事项。

# 确认与续接

- Gate 1：展示简报，解决用户决策，提问后停等明确确认；门禁权限遵循 [入口](../SKILL.md#mandatory-gates)。
- 表达方式：按 [沟通规则](../SKILL.md#沟通) 说明效果、用法、成本和限制。
- 延续授权：沿用有效批准；普通任务引用有效模块设计，不重启整轮采访。
- 变化处理：只补问缺失或变化的重要承诺，继续未受影响的已授权工作。
