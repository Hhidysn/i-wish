# I Wish

[English](README.md) | [简体中文](README.zh-CN.md)

许愿术，是凡人能掌握的最强大法术。
你只需要大声说出愿望，世界便为其赋予形状。

将尚未明确的产品愿望转化为可验证的产品结果，研究关键决策，按用户希望承担的技术责任调整指导方式，再规划、实现并证明结果。详见 [SKILL.md](SKILL.md)。

默认采用与任务规模相称的澄清方式，并沿用已有授权。只有在用户要求分阶段确认，或明确选择要求该流程的集成时，才启用审批 gate。较旧的 OpenCode 适配器仍可能强制执行 gate；便携 skill 的修改不会改变适配器代码。详见 [主机集成说明](references/host-adapters.md)。

运行时引用资料仅覆盖需求澄清、关键决策研究和游戏专项，按需读取。安装与兼容信息见主机集成说明。[行为案例](evals/cases.md)仅用于开发。独立副本和其他主机安装不会自动同步。
