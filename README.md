# I Wish

[English](README.md) | [简体中文](README.zh-CN.md)

Wish is the most powerful magic mortals can wield.
Speak your wish aloud, and the world gives it shape.

Shape an unsettled product request into a coherent, testable result, research
consequential choices, adapt technical guidance to the user's desired level of
control, then plan, implement, and prove the result. See [SKILL.md](SKILL.md).

Default to proportional clarification and carry existing authorization forward.
Use approval gates only when the user requests staged approval or explicitly
chooses an integration requiring it. Older OpenCode adapters may still enforce
gates; portable skill edits do not change adapter code. See
[host integration](references/host-adapters.md).

Runtime references cover clarification, consequential research, and games, and are read on demand. Installation and compatibility notes are linked above. [Behavioral cases](evals/cases.md) are development
material. Separate copies and host installations are not automatically synchronized.
