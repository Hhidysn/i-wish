# I Wish

[English](README.md) | [简体中文](README.zh-CN.md)

Wish is the most powerful magic mortals can wield.
Speak your wish aloud, and the world gives it shape.

Turn an unsettled project, module, or major refactor into clear outcomes,
researched choices, audited design and independently verified delivery.
One installable skill, two workflows; existing `$i-wish` invocation stays valid.

| Mode | Use for | Planning |
| --- | --- | --- |
| Lite | Bounded, reversible demos | Short cards, targeted research, one useful journey |
| Full | Coupled modules or consequential commitments | Shared contracts, module refinement, dependency tasks, milestone acceptance |

Invoke `$i-wish` and describe the outcome and constraints. Optionally say
“use lite” or “use full”; otherwise it explains its selection. Risk controls
remain required. Routine fixes and already-settled implementation use normal work.

Both modes default to subagents: independent design challenge, post-code test
authorship, separate fresh user experience checks. Open ideas use distinct-model
proposals; genuine research axes run concurrently where supported. Full adds
progressive module design and separate requirements/standards review contexts.
Gate 1 and Gate 2 are mandatory in both modes and design-only work: stop/wait
for explicit intent confirmation, complete actual online research before design,
then stop/wait for approval of the shown solution and delivery scope before files
or code. Clear requests, delegation, demos and reversibility waive neither gate.
Reuse actual unchanged approvals; explicit named-stage exceptions remain scoped. Missing mandatory evidence is reported as partial.

## Install and navigate

Copy or link this directory into your host's skills location: Codex
`~/.agents/skills/i-wish` or project `.agents/skills/i-wish`; Claude Code
`~/.claude/skills/i-wish`; OpenCode `~/.config/opencode/skills/i-wish` or
`.opencode/skills/i-wish`. Invoke `$i-wish` or `/i-wish` as your host supports.
Keep one source copy. The skill is a behavior contract; your host supplies dispatch,
fresh contexts, model routes and permissions.
