# I Wish

Shape an unsettled product request, research consequential choices, then implement
and verify the result. See [SKILL.md](SKILL.md).

Default to proportional clarification and carry existing authorization forward.
Use two approval gates only when the user requests staged approval or explicitly
chooses an integration requiring it. Older OpenCode adapters may still enforce
gates; portable skill edits do not change adapter code. See
[host integration](references/host-adapters.md).

References are read on demand. [Behavioral cases](evals/cases.md) are development
material. This is the customized installed copy; separate source checkouts and
other host installations are not automatically synchronized.
