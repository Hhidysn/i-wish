# 通用愿望、关键词化入口与按需编排深化

日期：2026-10-11。状态：Accepted。

## 已批准目标

用户确认：单包单入口（Q1-A）；关键词化（短动作句、去关联词、保留条件/权限/验收，Q3-②）；
机制级融合且引用只进参考文档、正文零引用（Q4-②）；无子代理降级为一次对抗性检查（Q5-②）；
模块级只在未批准的用户可见结果/成本/数据外发/不可逆影响时补确认（Q2-③）；
`docs/research/sources.md` 放仓库（Q4 附加）；删除 `game-projects.md`；
预算 SKILL 600 / lite 420 / plain 220，其余不变；任务拆分并入 Gate 2，不加第三道门禁。

## 决定

1. **通用化**：愿望不必是代码。文档、媒体、方案、配置与代码使用同一套字段、
   两道门禁和验收规则；`SKILL.md` 的 description 覆盖被动触发（新项目、模块改动、
   重大重构）与主动触发（任意"我想要……"），仍明确跳过日常小修。
2. **入口瘦身、深度下沉**：`SKILL.md` 从 649 降到 599 词；新增的编排细节放进
   按需加载的 `full.md`（任务包、就绪表、模块循环、BASE 与 brief/report/diff、
   有界复审）、`verification.md`（`Run/Expected/Observed`、产物候选身份、防降级审查）、
   `agents.md`（审计输入去偏、降级链）。
3. **验收触发改为"产物形成后"**，不再写 "after coding"；候选身份支持文档、渲染件
   与远程配置快照，不强制 git diff 或测试框架。
4. **模块级补确认绑定四类未批准影响**；普通 ticket 不重启采访，不新增第三道门禁。
5. **降级链显式化**：主代理一次对抗检查 → `non-independent` → 独立验收 pending →
   部分交付。
6. **删除 `game-projects.md`**；领域特化指南与"任意愿望"定位冲突。
7. **来源表独立**：`docs/research/sources.md` 记录机制、出处、许可与采纳边界；
   运行时正文不写引用、不复制第三方正文。Trellis（AGPL-3.0）与无许可证仓库
   只作机制参考。

## 备选

- 双独立技能包：显式调用更直接，但门禁与语言规范会复制成多份并漂移；未采用。
- 新增 `shape.md` / `tasks.md`：独立审计判定为零收益拆分（Shape 每次必读，
  任务细节仅 full 使用），未采用。
- 新增第三道 Plan 门禁：与"只有两道门禁"的用户决定冲突，且可用 Gate 2 内的
  任务拆分与阶段目标覆盖，未采用。
- 整体移植 superpowers 执行器或 Trellis `check` 自修：与"产出者不得充当独立验收者"
  冲突，未采用。

## 代价与验证

总运行字数由 4120 增至 4470（+8.5%），增量全部落在按需加载的深度文件；
常驻入口减少 50 词。深度增加换来 full 的编排可执行性，代价是首次阅读量上升。

验证：`node scripts/check.mjs`（结构、字数、链接与锚点）与
`node --test evals/check.test.mjs`（11 项）通过；另派新上下文探针与独立对抗审计，
结果记录在[验证记录](../history/2026-10-11-two-tier-refactor-validation.md)。
静态检查不证明流程实际被执行。
